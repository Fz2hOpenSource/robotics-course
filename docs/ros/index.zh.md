# ROS 简介

机器人操作系统 (ROS) 是一套帮助您构建机器人应用程序的软件库和工具。

## 核心概念

- **节点 (Nodes)**：执行计算的可执行文件。
- **话题 (Topics)**：节点交换消息的命名总线。
- **服务 (Services)**：节点之间的请求/回复通信。
