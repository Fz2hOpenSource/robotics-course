# 机器人仿真

本模块涵盖机器人仿真框架和最佳实践。

## 目录

- [Gazebo](gazebo.md) - ROS原生机器人仿真
- [Drake](drake_sim.md) - 高级操作仿真
- [MuJoCo](mujoco.md) - 用于 locomotion 的物理引擎
- [PyBullet](pybullet.md) - 快速原型仿真器

## 为什么需要仿真？

- 无硬件损坏的安全测试
- 快速迭代和调试
- 强化学习的并行训练
- 可重复的实验

## 仿真到真实迁移

弥合仿真与现实之间的差距：
- 领域随机化
- 系统辨识
- 渐进式微调
