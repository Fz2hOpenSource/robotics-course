# Acting, Planning, and Learning (LAAS Course)

This module covers the LAAS-CNRS course on Acting, Planning, and Learning.

## Course Overview

- **Authors**: Malik Ghallab, Dana Nau, Paolo Traverso
- **Source**: [projects.laas.fr/planning](https://projects.laas.fr/planning/)
- **Publisher**: Cambridge University Press, 2025
- **Focus**: Theory of planning, acting, and learning integration

## Topics Covered

### Planning Theory
- [Planning Problem Formulation](planning_problem.md) - Classical planning, PDDL
- [Planning Algorithms](algorithms.md) - Search-based, planning graphs
- [Temporal Planning](temporal.md) - Concurrent actions, time constraints

### Acting
- [Reactive Acting](reactive_acting.md) - Real-time response
- [Deliberative Acting](deliberative.md) - Planning-based control

### Learning
- [Learning from Experience](learning.md) - Skill refinement
- [Planning with Learning](planning_with_learning.md) - Integrated approaches

## Prerequisites

- Basic AI concepts
- Search algorithms (A*, BFS, DFS)
- (Recommended) [Robotics Basics](../robotics_basics/index.md)
