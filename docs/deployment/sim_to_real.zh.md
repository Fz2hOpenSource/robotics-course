# 仿真到真实迁移

## 现实差距

仿真与真实之间的差异：
- 物理模型不准确
- 传感器噪声和延迟
- 执行器非线性

## 领域随机化

训练期间随机化仿真参数：

```python
sim_params = {
    'gravity': random.uniform(9.7, 9.81),
    'friction': random.uniform(0.5, 1.5),
    'sensor_noise': random.uniform(0.01, 0.1)
}
```

## 系统辨识

学习真实机器人参数：
1. 收集真实世界数据
2. 拟合仿真参数
3. 改进模型

## 渐进式微调

1. 在仿真中训练
2. 在真实机器人上微调（有限数据）
3. 渐进式领域适应
