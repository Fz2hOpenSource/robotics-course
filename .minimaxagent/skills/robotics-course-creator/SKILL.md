# Robotics Course Creator - 机器人课程教案生成器

## 技能描述

这是一个专门为机器人技术开发者设计的AI辅助工具，帮助将机器人项目、学习笔记、课程内容快速转换为结构化的B站视频教案和配套文档。

## 核心能力

1. **内容分析** - 理解项目结构、代码逻辑、技术要点
2. **教案生成** - 创建适合B站讲解的视频脚本结构
3. **分镜设计** - 规划代码演示、动画说明、互动环节
4. **文档配套** - 生成MkDocs/HTML格式的配套教程
5. **PPT生成** - 创建演示用的幻灯片

## 使用场景

### 场景1: 转换项目为教程
```
用户: "帮我把 piper-X 项目做成B站教程"
AI会:
1. 分析项目结构和代码
2. 生成视频分镜脚本
3. 创建配套的MkDocs文档
4. 生成演示PPT
```

### 场景2: 将课程笔记整理成教案
```
用户: "帮我把 LAAS 规划课程的笔记整理成B站教案"
AI会:
1. 理解课程内容结构
2. 分解为10-15分钟的视频章节
3. 生成讲解脚本和代码演示说明
4. 创建配套文档
```

### 场景3: 创建系列教程
```
用户: "我要做一个机器人操作系列教程"
AI会:
1. 规划课程大纲和难度梯度
2. 设计每集的内容和时间分配
3. 生成系列化的教案模板
```

## 输出格式

### 1. 视频教案 (Video Lesson Plan)
```markdown
# 第X集: [主题名称]
- 时长: XX分钟
- 目标受众: 初级/中级/高级
- 难度: ⭐⭐⭐

## 分镜脚本
| 时间点 | 内容 | 画面 | 备注 |
|--------|------|------|------|
| 0:00 | 开场 | 标题动画 | 引出主题 |
| 2:00 | 概念讲解 | 示意图 | 通俗易懂 |
| 5:00 | 代码演示 | 屏幕录制 | 分步骤讲解 |
...

## 代码演示清单
- 演示1: [代码片段]
- 演示2: [代码片段]

## 互动点
- 提问: xxx?
- 练习: 尝试修改xxx

## 配套资源
- 文档链接
- 代码仓库
- 延伸阅读
```

### 2. 配套文档 (Documentation)
```markdown
# 主题名称

## 学习目标
- 理解xxx原理
- 掌握xxx实现
- 能够xxx应用

## 理论部分
[详细的技术讲解]

## 实践部分
[代码实现和分析]

## 常见问题
Q: xxx?
A: xxx

## 练习题
1. xxx
2. xxx
```

### 3. 演示PPT (Presentation)
```markdown
# 幻灯片结构
1. 封面 - 标题、副标题、作者
2. 目录 - 本集内容概览
3. 概念 - 核心原理图解
4. 代码 - 分步骤演示
5. 演示 - 运行效果展示
6. 总结 - 要点回顾
7. 下集预告
```

## 使用方法

### 启动技能
用户直接描述需求，如：
- "帮我做B站教程：机器人运动学"
- "把 piper-X 项目转成教案"
- "创建一个ROS2入门系列教程"

### 输入信息
AI会引导用户提供：
1. 项目/课程的技术内容
2. 目标受众（初学者/进阶/专业）
3. 视频时长偏好
4. 是否有特定重点

### 协作流程
```
1. 需求确认 → 2. 内容分析 → 3. 教案生成 → 4. 文档创建 → 5. 审核修改
```

## 输出位置

生成的文件保存在用户工作目录：
- 教案脚本: `{topic}/lesson_plan.md`
- 文档教程: `docs/{topic}/`
- 演示PPT: `slides/{topic}/`

## 特色功能

### 1. 代码高亮与解释
自动为代码添加：
- 行号标注
- 重点代码高亮
- 分步解释注释

### 2. 可视化建议
为复杂概念提供：
- Mermaid图表建议
- 动画描述
- 示意图说明

### 3. 互动设计
- 弹幕问题预设
- 练习题设计
- 延伸挑战任务

### 4. 时间管理
- 精确到秒的分镜设计
- 节奏把控建议
- 高潮点设计

## 适用技术栈

- 机器人学: 运动学、动力学、控制理论
- 仿真: Drake, MuJoCo, Gazebo, PyBullet
- 规划: 运动规划、任务规划、MDPT
- 感知: 视觉、点云、深度学习
- 强化学习: PPO, SAC, TD3
- 框架: ROS, ROS2, MoveIt

## 注意事项

1. **技术准确性** - 确保代码和原理解释正确
2. **受众适配** - 根据目标调整讲解深度
3. **实践导向** - 每集包含可运行的代码示例
4. **系列连贯** - 多集内容有合理的难度递进
