# Contributing to Robotics Course

Thank you for your interest in contributing to this robotics course!

## How to Contribute

### 1. Documentation Improvements

- Fix typos or grammatical errors
- Improve explanations
- Add more examples
- Translate content (we welcome translations!)
- Improve code comments

### 2. Code Examples

- Test all code snippets
- Add additional examples
- Fix compatibility issues
- Update deprecated APIs

### 3. New Content

- Suggest new topics
- Write new tutorials
- Add exercises and solutions

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test locally with `mkdocs serve`
5. Submit a pull request

## Style Guide

### Markdown

- Use ATX-style headers (`#`, `##`, etc.)
- Code blocks with language hints
- Tables for structured data
- Mathematical formulas in LaTeX format

### Mathematical Formulas

Use LaTeX notation:

**Inline**: Use `$...$` or `\(...\)`
```markdown
The equation is $f(n) = g(n) + h(n)$.
```

**Display**: Use `$$...$$` or `\[...\]`
```markdown
$$
f(n) = g(n) + h(n)
$$
```

### Code Blocks

Always specify the language:
```markdown
```python
def hello():
    print("Hello!")
```
```
