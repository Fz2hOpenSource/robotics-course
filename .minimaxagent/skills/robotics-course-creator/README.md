# Robotics Course Creator 使用指南

## 快速开始

### 1. 激活技能
在对话中直接描述你的需求，例如：

```
帮我做一个关于 MuJoCo 仿真入门的 B站教程
```

### 2. 提供信息
AI 会引导你提供：
- 技术内容或项目路径
- 目标受众
- 期望时长
- 重点内容

### 3. 获取输出
AI 将生成：
- 📝 视频教案脚本
- 📚 配套文档
- 📊 演示PPT（可选）


## 技能配置

### 可调整参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `duration` | 单集时长 | 15分钟 |
| `audience` | 目标受众 | 有基础 |
| `style` | 讲解风格 | 技术深入 |
| `output_format` | 输出格式 | md |

### 自定义模板

如需使用自己的模板，可以在对话中指定：
```
用我的模板生成 [主题] 的教案
```

## 文件输出

生成的文件保存在当前工作目录：

```
{workspace}/
├── lesson_plans/           # 视频教案
│   ├── ep01_xxx.md
│   └── ep02_xxx.md
├── docs/                   # 配套文档 (MkDocs)
│   └── {topic}/
│       ├── index.md
│       └── ...
├── slides/                 # 演示PPT
│   └── {topic}/
│       ├── slide01.html
│       └── ...
└── code_demos/            # 代码示例
    └── {topic}/
        ├── demo1.py
        └── ...
```

## 常见问题

### Q: 生成的内容可以直接用吗？
A: 生成的是初稿，建议根据个人风格调整语言和节奏。

### Q: 支持哪些技术主题？
A: 机器人学、ROS、仿真（Drake/MuJoCo/Gazebo）、运动规划、视觉、强化学习等。

### Q: 可以生成系列化的教程吗？
A: 可以！告诉我你想做系列教程，我会帮你规划整体大纲和每集内容。

### Q: 如何让 AI 更了解我的项目？
A: 提供项目路径、README、或关键代码，AI 会先分析再生成。

---

## 最佳实践

1. **先规划后制作** - 先用技能生成大纲，确认后再深入
2. **保持系列连贯** - 每集结尾预告下集内容
3. **实践导向** - 每集包含可运行的代码示例
4. **控制节奏** - 复杂内容拆分成多集
